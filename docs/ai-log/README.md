# AI 활용 기록 — 아카이빙 프로토콜

이 폴더가 제출물 1번(AI 활용 기록)의 원천이다. 마지막에 여기 쌓인 것을 docx/pdf로 정제해 제출한다.

## 기록 단위

세션(작업 묶음) 1개 = 파일 1개. 파일명: `YYYY-MM-DD-NN-작업명.md`

## 항목 형식 — "프롬프트 → AI 답변 → 나의 대응"

```markdown
### [순번] 작업 한 줄 요약

**도구**: Claude Code (Claude Fable 5) / Codex (gpt-5.6) 등 — 모델명까지
**내가 시킨 것**: (실제 프롬프트 발췌 — 날것 그대로)
**AI가 한 것/답한 것**: (핵심 발췌)
**나의 대응**: 수용 / 의심 → 검증 → 재요청 / 기각 (이유 포함)
```

## ⚠️ 오답 태그 (가장 중요)

AI가 틀렸거나 엉뚱하게 답한 순간은 **발생 즉시** `⚠️ 오답` 섹션으로 박제한다:
틀린 답 원문 → 내가 어떻게 알아챘나 → 어떻게 바로잡았나(재요청 프롬프트 포함) → 결과.
회사가 명시적으로 "가장 보고 싶다"고 한 부분이다. 사후에 지어내지 않는다 — 실시간 기록만.

## 규칙

- 날것 우선. 사후 각색 금지 (회사도 "정제 불필요, 날것 환영" 명시)
- 공개 레포 가드: 개인정보·시크릿·무관한 프로젝트 정보는 발췌 시 마스킹
- 기록 누락 방지: 세션 종료 전 반드시 해당 세션 로그 파일 커밋
- **적용 메모리/규칙 기록 (v2)**: 세션마다 발동한 작업 규칙(영구 메모리)·가드(stop-hook, Codex 게이트)를 명시 — 전체 하네스 구성은 `docs/02-작업방식-하네스.md`
