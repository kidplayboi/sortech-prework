### ⚠️ 오답 1호 — "GitHub Pages CDN이 10분간 옛 버전을 보여줄 것"

**AI의 원래 주장** (설계 단계): GitHub Pages는 CDN 캐시가 약 10분이라, 배포 직후 "원본은 새 버전·사용자 화면은 옛 버전"인 L3 상황이 연출 없이 실재로 재현된다.
**실측 반박**: v1.0.1 실배포 → 50초 뒤 두 시점 모두 v1.0.1 (불일치 미발생). 헤더 실측: `X-Cache: HIT` + `Age: 52`인데 내용은 새 버전 = **GitHub Pages는 배포 시 CDN 캐시를 즉시 퍼지함**. 원래 주장이 틀렸음.
**어떻게 알아챘나**: 예측(WARN 발생)과 실측(OK)이 다르자, 결과를 받아들이기 전에 응답 헤더를 직접 떠서 원인 확인.
**교정**: ① 옛 버전 잔상의 실제 주범은 방문자 **브라우저 캐시**(max-age=600을 브라우저가 10분간 존중) → L3에 캐시 정책 실측(`max-age` 파싱)을 추가해 "브라우저 잔상 최대 N분"을 함께 보고하도록 코드 수정 ② CDN 두-시점 비교는 유지 — 배포 시 퍼지를 안 하는 CDN/호스팅(실제 고객사 환경 다수)에선 여전히 유효 ③ 녹화 씬 2는 "실제 브라우저 창에 옛 버전이 남아 있는 장면"으로 변경 예정.
