## 불변식 (재개 시 반드시 유지)

1. **기록 실시간** — 세션마다 `ai-log/` 파일 1개, "프롬프트→AI 답변→나의 대응" + 적용 메모리/규칙 명시. ⚠️오답은 발생 즉시 박제 (**현재 28호까지** — 제출물의 핵심 자산)
2. **공개 레포 가드** — 시크릿·개인정보·무관 프로젝트 정보 유입 금지
3. **검증 규율**: 수리 보고는 시퀀스 재현으로 검증 / 동시성 테스트는 반복 실행 / 같은 텍스트·구조 수정은 grep 전수 / "보장" 서술은 실측 책임 동반
4. **음성 대조는 테스트 추가 시점에도** — 새 회귀 테스트는 "결함 있는 코드에서 실제로 RED가 되는가"를 먼저 확인한다 (17차 교훈 ②: 주기 12 테스트가 실패 불가 구조였다). **대조 장치 자체도 검증한다** — 상수를 기본 인자로 박으면 패치가 안 먹어 대조가 아무것도 제거하지 않는다 (오답 27호)
5. **계측기를 먼저 의심한다** — 프로브 결과가 코드 변경 방향과 어긋나면 별도 프로세스로 재현부터. 임시 포트 고갈이 만든 `unknown`을 판정으로 집계하면 없는 문제를 만든다 (오답 28호)
5. **게이트**: 슬라이스 완료마다 Codex 교차 게이트(모델 핀 **gpt-5.6-sol + xhigh** — 평문 gpt-5.6은 400 차단), P1/P2 0까지 반복. 맹목 수용 금지
6. 파일 500라인 금지 · 한 파일 한 책임 · 작업 단위 커밋 + 푸시 후 원격 해시 대조
