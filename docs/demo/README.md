
3분간 그 창을 건드리지 않으면 끝난다. 대본·타이밍·읽을 시간이 전부 스크립트에 있다.
결과물 = `C:\Users\test\sortech-demo-onetake.mp4` (레포 **밖**에 저장 — 실수 커밋 차단)

## ⚠️ 전제: 깨끗한 데스크톱

녹화는 **화면의 사각형을 찍는 것**이라 그 자리에 무엇이 있든 찍힌다.
리허설에서 실제로 다른 프로젝트의 작업 세션과 메신저 창이 그대로 녹화됐고,
그대로 제출했으면 공개 제출물에 무관한 정보가 들어갈 뻔했다(즉시 폐기).

그래서 **작업 전 순서**:
1. 재부팅하거나, 최소한 메신저·브라우저·다른 작업 창을 전부 닫는다
2. 데모용 터미널 하나만 띄운다
3. 녹화 중 알림 팝업이 뜨지 않게 집중 모드를 켠다
4. 끝난 뒤 영상을 **직접 재생해서 눈으로 확인**한다 — 이 단계를 건너뛰지 않는다

`run-and-record.ps1`은 자기 창(제목 마커 `SORTECH-ONETAKE`)이 최상위일 때만 녹화를
시작하고, 아니면 **중단**한다. 바탕화면 전체로 대체하는 경로는 아예 없다.

## 파일

| 파일 | 역할 |
|---|---|
| `run-and-record.ps1` | 녹화 + 데모 실행 (형이 실행하는 진입점) |
| `demo.ps1` | 3분 대본 — 5개 구간, 읽을 시간 포함 |
| `l5_demo.py` | L5 구간 — 재현 서버로 진짜 클로킹 vs 회전 콘텐츠 실연 |
| `record.ps1` | 녹화기 단독 실행용(디버깅) |

## 대본 구성

| 구간 | 내용 | 왜 넣었나 |
|---|---|---|
| 0 | 타이틀 3줄 | 평가자가 "이게 뭐지"를 추측하지 않게 |

| 2 | `deploy --expect-version 1.0.1` | 앵커 계약 — 원본·사용자 둘 다 그 버전이어야 통과 |
| 3 | `deploy --expect-version 9.9.9` | 실패도 반드시 1회 통보(무소식 없음) + 텔레그램 |
| 4 | L5 클로킹 실연 | **같은 관측**을 🔴과 🟠→🟢으로 가르는 지점 |
| 5 | 클로킹 회귀 테스트 | 게이트 20라운드가 남긴 고정핀 |
| 6 | 알려진 한계 | 못 하는 것을 먼저 말한다 |

sites.json·state.json은 건드리지 않는다 — 녹화가 중간에 끊겨도 레포가 더럽혀지지 않게.
